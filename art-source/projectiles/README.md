# Aerial projectile art sources

`aerial-projectiles-plate.png` was generated with the built-in ImageGen
workflow on a flat chroma background. It contains the Curveball Swarm football
and Golden Boot Seekers cleat as two isolated, center-safe subjects.

`curveball-src.png` and `golden-boot-src.png` retain the exact square source
crops. Runtime sprites in `public/art/projectiles/` use a locally removed matte,
transparent padding and a normalized 128x128 canvas. Both runtime sprites were
validated as RGBA images with genuinely transparent pixels.

Shared direction: premium stylized 2.5D top-down game asset, crisp silhouette
at 32 px, cyan/gold motion energy, no text, brand, logo or watermark.

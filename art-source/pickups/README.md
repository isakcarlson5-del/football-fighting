# Pickup art sources

The six source plates here were generated with the built-in ImageGen workflow
on flat removable chroma-key backgrounds. Alpha-cleaned 128x128 runtime PNGs
live in `public/art/pickups/`; procedural Canvas sprites remain as load fallbacks.

- `xp-1`: compact cyan hex crystal.
- `xp-2`: richer gold double-point crystal.
- `xp-3`: rare purple crown crystal.
- `coin`: thick gold token with generic football-panel relief.
- `heal`: green recovery bottle with a geometric white medical cross.
- `trophy`: original silver-and-gold football cup with oversized handles and no
  competition branding.

Shared constraints: premium 2.5D top-down icon, strong outline, one centered
opaque object, readable at 32 px, no text, watermark, logo, shadow or extra prop.
